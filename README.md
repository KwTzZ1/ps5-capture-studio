# PS5 Capture Studio

Affichez l'image et le son de votre PS5 sur votre PC Windows avec une clé d'acquisition HDMI (UGREEN et compatibles UVC), en très faible latence.

## Télécharger

**[Télécharger la dernière version](https://github.com/KwTzZ1/ps5-capture-studio/releases/latest)** → fichier `PS5CaptureStudio-Setup-x.x.x.exe`

Installation en un clic, sans droits administrateur. Le logiciel se met ensuite **à jour tout seul**.

> Au premier téléchargement, Windows peut afficher « Windows a protégé votre ordinateur » : cliquez sur **Informations complémentaires** puis **Exécuter quand même**.

## Fonctionnalités

- Image 1080p 60 ips ou 2K, très faible latence, son de la console
- Enregistrement vidéo (encodage matériel NVIDIA / Intel / AMD) et **clips instantanés** des dernières secondes
- Éditeur de clips et **partage par lien** (lisible directement dans Discord)
- **Diffusion sur téléphone** (QR code, télécommande)
- Réglages d'image : conversion HDR → SDR, contraste, netteté, modes daltoniens, réticule
- Interface Windows 11, mini-lecteur, raccourcis globaux

## Configuration requise

- Windows 10 / 11 (64 bits)
- Clé d'acquisition HDMI USB (UVC)
- Sur la PS5 : *Paramètres › Système › Sortie HDMI › Activer HDCP : désactivé*
